Voice gadget: e-paper UI concepts

Six directions for the 1.54" 200×200 1-bit screen. Every screen is drawn into a real 200×200 buffer of pure black/white pixels (no greys), the same as the panel. Click a screen to download it as a 1-bit PNG. Star the ones you like and leave notes; they're saved in this browser.

Size 


  
Fonts on the device screens: a classic 5×7 bitmap font drawn at integer scales (1×–4×), except the "Poster" concept, which uses a heavy sans run through a hard 1-bit threshold. Icons are 16×16 1-bit sprites scaled by whole numbers.
